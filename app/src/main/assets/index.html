✋ Esqueleto da mão

Área uniforme: cubo automático aproximado. Ou toque na imagem. Faça uma pinça com polegar e indicador dentro do cubo para pegar; abra para soltar. Segurando o cubo, gire a mão para rotacionar e aproxime-a para aumentar.

Assistente offline: ative a câmera para começar.
